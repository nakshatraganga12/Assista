# 🎓 Assista – Your Personal College Assistant

**Assista** is a smart AI-powered mobile and web application designed to simplify college life. It centralizes academic tools, student resources, reminders, and campus services—all in one place.

---

## 🚀 Features

- 🗳️ Anonymous Suggestion Box  
- 📆 Exam & Assignment Tracker  
- 📚 Notes and Syllabus Repository  
- 🔔 Reminders and Notifications  
- 📊 Attendance & Progress Tracker  
- 🧾 Online Permission Slip System  
- 🧠 Daily Motivation & Productivity Tools  
- 🧑‍🏫 Teachers' Timetable View  
- 📖 Library Book Search & Due Tracker  
- 📝 Previous Year Questions Archive  
- 🧑‍🎓 Alumni Events & Interaction  
- ✅ Daily To-Do List  
- 📌 Important Contact Directory*  

---

## 🛠 Tech Stack

| Area         | Technology                     |
|--------------|--------------------------------|
| Frontend     | HTML, CSS, JS (from Stitch/Uizard), Flutter (optional) |
| Backend      | Python (FastAPI or Django REST)|
| Database     | Firebase / PostgreSQL / MongoDB|
| Auth         | Firebase Auth / Custom OAuth   |
| Hosting      | GitHub + Railway / Vercel / AWS|
| Design       | Uizard for UI Prototypes       |
| Version Ctrl | Git + GitHub                   |
